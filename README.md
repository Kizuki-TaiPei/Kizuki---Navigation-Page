# KIZUKI Navigation Page

## 简体中文

这是一个基于瑞士现代主义排版设计的导航页面。

### 特性

- 瑞士现代主义排版风格
- GSAP 动画效果
- 响应式设计，支持桌面端、平板端、移动端
- 无障碍设计，无图标干扰

### 文件结构

```
/
├── index.html    # 主页面
├── style.css     # 样式文件
├── script.js     # JavaScript 脚本
├── favicon.ico   # 网站图标
└── main.jpg      # 背景图片
```

### 技术栈

- HTML5
- CSS3 (CSS Variables, Grid, Flexbox)
- JavaScript (ES6+)
- GSAP 动画库
- Google Fonts (Inter)
